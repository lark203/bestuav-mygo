# bestuav-mygo 侧栏重设计：去自定义标题栏、去紫色主题、跟随系统

> 日期：2026-10-28
> 框架：`github.com/egoist/mygo` v0.7.1（纯 Go 原生 UI，GPU 自绘）
> 范围：`main.go`（入口/结构体/视图骨架）、`icons.go`（图标）、`sidebar.go`（品牌头+侧栏）、`pages.go`（首页/卡片/表/占位/弹窗）、`main_test.go`（无业务页改动，仍为占位框架）

## 一、目标与决策

用户确认两项前提：

1. **主题明暗**：去掉紫色强调色后，改为**跟随系统明暗**（`mygo.ThemeSystem`），不再强制深色。
2. **菜单重组**：保留全部现有菜单项，按**功能域重新分组**，并为每一项配 **Lucide 风格独立图标**（替换原先大量复用的 `iconFolder`/`iconKey`/`iconBox`）。

## 二、改动点

### 1. 去除自定义标题栏（任务3）
- `main.go` 的 `WindowOptions` 删除 `TitleBarStyle: mygo.TitleBarHidden`、`TitleBarHeight: 44`、`BackgroundColor: "#15131f"`，改回系统默认标题栏。
- 删除 `titleBar` / `appLogo` / `titleIconBtn` 三个方法及 `view()` 中对它们的调用。
- 品牌标识"量子科学"移至**侧栏顶部**作为品牌头（`brandHeader`：原子图标 + 文字，无紫色方块）。

### 2. 去除自定义颜色（任务6）
- `view()` 删除 4 行紫色强调色覆盖（`t.Accent` / `AccentHover` / `AccentPressed` / `AccentText`）。
- 侧栏 / 图标 / 卡片等一律使用 mygo 系统主题色；`SidebarItem` 内部本就用 `t.Accent` 渲染图标、选中态用系统强调色（已读 `sidebar.go` 源码确认）。

### 3. 侧栏重设计（任务5，参考 VS Code / Linear / Ant Design Pro）
- 顶部品牌头（图标 + "量子科学"）+ 分隔线。
- 按功能域分组（原为"图标/个人资料/组件演示/功能演示"演示桶）：
  - **主导航**：首页
  - **工具箱**：生成license、生成用户密码、公钥私钥、异步任务、调试中心
  - **个人中心**：基本信息、安全设置
  - **组件演示**：按钮、输入框、表格、卡片、标签页
  - **功能演示**：图表、表单、弹窗、Task、虚拟列表、异步开发、GRAND_DEMO
  - **设置**（底部）
- 每项独立 Lucide 风格线性 SVG 图标（`stroke="currentColor"`，24×24），共 24 个图标定义。
- 分组默认**展开**（`newApp()` 中 `openTools/Profile/Components/Functions = true`），首屏即可见全部菜单。

### 图标库选型结论
mygo 无内置图标包，全部走 `ui.MustParseSVG` 内联 SVG。推荐 **Lucide**（MIT、~1500、24×24 线性 `currentColor`）作来源，备选 Tabler / Feather / Heroicons。选用线性 + currentColor 集最契合 mygo（避免多色固定色图层在主题切换时不自适应）。

## 四、补充修复（2026-10-28 晚）：侧栏占满高度 + 展开滚动 + 文件拆分

用户反馈截图：左侧菜单未占满左侧高度（上下留白），且展开后无滚动。

### 根因
- 外层侧栏 `Column` 只设了 `Width(220)`，未撑满父 `Row` 高度。
- `ui.Sidebar` 原写法 `.Fill()`（高度 100%）+ 上方 52px 品牌头形成**循环/溢出**：`Column` 高度由内容决定，而 `Sidebar` 又要占满该高度，导致高度不确定、未顶满。
- 阅读 `ui/sidebar.go` 源码确认：**`ui.Sidebar` 内部本就是 `Scroll`**（`coreSidebar` 第一行 `coreScroll(c)...`），滚动能力已内置，只是此前没拿到确定高度所以不触发。

### 改动
1. **侧栏占满高度**：外层 `Column` 改为 `Width(220).HeightPercent(100)`，撑满父 `Row`；`brandHeader` 固定 `Height(52).Shrink(0)`。
2. **展开可滚动**：`ui.Sidebar(...)` 改为 `.Width(220).Grow(1)`，吃掉剩余确定高度（品牌头固定、菜单区滚动）。菜单展开超出窗口高度时自动出现滚动条。
3. **拆分文件**（用户要求不要把代码放一个文件）：
   - `main.go`：入口 `main`、结构体 `app`、`newApp`、`pageTitles`、`view`。
   - `icons.go`：24 个 Lucide 风格线性 SVG 图标定义。
   - `sidebar.go`：`brandHeader` + `sidebar`。
   - `pages.go`：`homePage` / `overviewCard` / `productTable` / `placeholderPage` / `dialog`。
   - 同属 `package main`，测试（`newApp`/`render`）仍在 `main.go`，不受影响。

### 追加（2026-10-28 晚）：设置项固定侧栏底部、不随滚动
- 将"设置"从 `ui.Sidebar` 滚动区移出，放在侧栏 `Column` 底部固定区：品牌头固定 → 菜单区 `Grow(1)` 滚动 → 底部分隔线 → 设置项固定（均 `Shrink(0)`）。
- `ui.SidebarItem` 依赖 `ui.Sidebar` 上下文（`c.sidebar`）才能注册点击/选中，置于其外会失效；故底部"设置"用自定义 `Row` + `.Clicked()`（自动置 `flagClickable`）+ `.Hovered()` 实现点击与 hover 高亮，并据 `a.page == "settings"` 做选中态高亮，与菜单区选中逻辑一致。
- 验证：`go build` / `go vet` / `go test` 全绿。

## 五、风险与后续

1. **未做真实渲染验证**：本环境无显示器，`go tool mygo dev` 的窗口实际渲染（系统标题栏、跟随系统的浅/深色表现、品牌头布局、图标显示）需在你本机有显示器会话中目测确认。
2. **未提交**：按规范改动未提交，待你审核后由你提交推送。
3. **`mygo.ThemeSystem` 行为**：若希望默认浅色或默认深色，可改为 `mygo.ThemeLight` / `mygo.ThemeDark`；当前为跟随系统。
4. **分组是否默认展开**：当前默认展开以贴近原"全可见"观感；若想要更紧凑的收起式导航，可将 `newApp()` 中四个 `open*` 改为 `false`。
