# 内容区三种公共布局

日期：2026-11-09

## 背景

内容区原来只有一种形态：页头（标题 + 右侧工具条）+ 一段统一滚动的内容。
实际页面出现两类新需求：

1. 页头要能说明「当前在看什么」——副标题（项目名 / 仓库名 / 任务名），
   以及放一个下拉框、一行文本之类的组件；
2. 有些页面需要**切换视图**（概览 / 明细 / 设置），有些需要**左列表 + 右详情**。

这些都属于骨架能力，不该每页各写一套，因此扩展 `shell.Content`，并在菜单里
放两页「活文档」：**布局示例 → 标签页布局 / 主从布局**。

## 三种样式

| 样式 | 用法 | 页头 | 滚动 |
|---|---|---|---|
| 标准 | `shell.Content{Title, Subtitle, Extras}` | 标题 + 副标题 + Extras + 工具条 | 统一滚动 |
| 标签页 | `shell.Content{Tabs, Tab, OnTab}` | 标题 + tab（**无副标题**）+ Extras + 工具条 | 统一滚动 |
| 主从 | `shell.Content{Fill:true}` + `shell.Split` | 同标准 | 左右两栏各自滚动 |

### 页头固定高度

`shell.HeaderHeight = 52`。`Extras` 被包在 `Height(HeaderHeight).Clip()` 的容器里：
组件再高也只占页头这一行，不会把标题栏撑高（有测试
`TestHeaderExtrasKeepHeaderHeight` 覆盖）。tab 用 `ui.Segmented`，同样在 52px 内。

### 副标题（与标题底部对齐）

`ContentOptions.Subtitle`：放在与标题同一个 `AlignItems(End)` 的子行里，**两行文字底部对齐**：

- 有 `Tabs` 时不渲染（位置让给 tab）；
- 业务侧自己决定内容，例如 mygo 里「任务执行中」优先显示任务名，
  主从示例显示当前选中的列表项。

### Extras

`ContentOptions.Extras func()`：标题右侧、工具条左侧的自定义组件容器。
可以放文本、`choice.Dropdown` 之类的单行控件；不要放会换行的多行内容
（高度会被裁掉）。

### 标签页

```go
tabs, idx, onTab := a.pageTabs() // 页面自己决定
shell.Content(c, t, shell.ContentOptions{
    Title: "示例", Tabs: tabs, Tab: idx, OnTab: onTab, Body: ...,
})
```

设置页就是第一个真实用户：四个分组从正文里的 `ui.Segmented` 搬到页头，
省掉一行垂直空间；分组状态仍存在页面私有状态里（`a.settingsGroup()`）。

### 主从 / 三段式

```go
// ContentOptions.Fill = true
shell.Split(c, t, &a.split, 240, 520, func() { // 左栏默认 320，可拖动 240–520
    shell.SplitListScroll(c, nil, func() { /* 卡片列表 */ })
}, func() {
    if selected == 0 {
        shell.SplitEmpty(c, t, "从左侧选择一个项目")
        return
    }
    shell.SplitDetailScroll(c, nil, func() { /* 详情 */ })
})
```

- 左栏宽度默认 320，可拖动中间分隔线调整（240–520px，右栏至少留 300px）；\n  状态放在页面的 `shell.SplitState` 里，拖拽后跨帧保留；\n- 拖动算法：`W += (x - x0)`（局部坐标增量），分隔线移动量已含在局部坐标里，不会抖动；
- 两栏各自 `ui.Scroll`，左栏滚动不影响右栏；
- 未选中时右栏用 `SplitEmpty` 给一句提示，而不是纯白。
